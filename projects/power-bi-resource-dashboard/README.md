# Power BI Operational Performance & Resource Planning Dashboard

## Project Overview
An interactive Power BI dashboard project using fictional operational and staffing data to support workload monitoring, SLA analysis and resource planning.

## Tools
- Power BI Desktop
- Power Query
- DAX
- Excel

## Dashboard Features
- Executive KPI summary
- Workload and queue trends
- SLA performance monitoring
- Resource capacity and active FTE
- Team performance comparisons
- Interactive filters and visualisations

## Project Objectives
- Identify operational bottlenecks
- Monitor incoming and completed work
- Compare workload with available staffing
- Support data-driven management decisions

## Status
In development

## Data
Synthetic demonstration data only. No confidential organisational information.
